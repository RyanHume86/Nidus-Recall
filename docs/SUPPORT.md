# Browser Support

## Supported browsers

| Browser | Minimum version |
|---|---|
| Chrome | 110+ |
| Edge | 110+ |
| Firefox | 110+ |
| Safari (macOS and iOS) | 16.4+ |
| Samsung Internet | 21+ |

## Not supported

- Internet Explorer (all versions)
- Safari versions below 16.4 (pre-2023)

## Notes

Nidus Recall uses modern web features including ES2022, CSS cascade layers, and IndexedDB. Browsers older than those listed above may display the app incorrectly or not at all.

Users on unsupported browsers will see a non-blocking banner advising them to upgrade.
