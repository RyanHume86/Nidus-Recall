## CI Integration

E2E tests run on PRs labelled `e2e` via `.github/workflows/e2e.yml`.

To run locally:
```bash
npx playwright test
# With credentials:
E2E_EMAIL=your@email.com E2E_PASSWORD=yourpass npx playwright test
```
